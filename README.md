# Swordsmen Virtual Squadron (SWD-085) - Web Portal

## 📖 About the Project
SWD-085 is the official web portal for **Swordsmen Virtual Squadron**, an international virtual aviation community focused on organized flight simulation, shared learning, and camaraderie. 

This project aims to centralize the squadron's identity, news, events, and documentation, providing a seamless and professional experience for both current members and prospective recruits. While Discord remains our primary communication hub, this platform serves as the public-facing reference point and an administrative tool for event coordination and membership applications.

## 🎯 Project Scope (MVP)
This repository contains the codebase for the Minimum Viable Product (MVP), which focuses on:
- **Public Portal:** Institutional information, mission, and values.
- **News & Events:** Public announcements and a calendar of upcoming operations.
- **Documentation Library:** Centralized repository for manuals, guides, and resources.
- **Recruitment & Event Forms:** Simplified application forms for prospects and event registrations.
- **Admin Panel:** Editorial interface for authorized personnel to manage content.

*Out of Scope:* Operational flight management, in-game aircraft slotting, individual rankings, and deep DCS server integrations.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (SCSS/Tailwind structure), Vanilla JavaScript (Vanilla TS planned). 
- **Backend:** Python (FastAPI/Flask) - *To be implemented by the backend team.*
- **Database:** SQL (PostgreSQL/Supabase) - *To be implemented by the backend team.*
- **Design System:** Custom BEM methodology with a dark/gold "Milsim" aesthetic.
